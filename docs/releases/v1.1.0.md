_Released 2026-10-20 · Stable_

## In one sentence

StreamFetch 1.1 makes long-running downloads restart-safe, lets you choose
individual collection items, adds live player visuals, and brings the complete
experience to a localized native desktop shell.

## What changed

### Added

- Durable JSON-backed download jobs that survive closing and restarting StreamFetch.
- Safe recovery of interrupted jobs as paused work that can be resumed intentionally.
- Per-item selection after inspecting a playlist, channel, set, or profile.
- Optional live waveform and audio-spectrum modes in the expanded player.
- English and German UI with system-language detection and in-app switching.
- A native pywebview launcher and a PyInstaller profile for standalone desktop builds.
- The new StreamFetch logo in the app bar, sidebars, browser tab, and packaged app assets.

### Improved

- Increased collection inspection to the configured safety limit, capped at 500 items.
- Kept mixed input useful by replacing collection URLs with selected entry URLs while
  preserving direct media URLs.
- Localized the primary download, library, queue, metadata, and player workflows.
- Bundled the app entry point and logo inside wheel installations.

### Fixed

- Prevented interrupted background work from disappearing after an app restart.
- Normalized flat YouTube collection entry IDs into downloadable video URLs.
- Throttled progress persistence so durable jobs do not create unnecessary disk writes.

## Upgrade notes

No library migration is required. Pull the release and reinstall the package:

```bash
git pull
pip install -e .
streamlit run app.py
```

Existing `.streamfetch/library.db` databases remain compatible. StreamFetch creates
`~/.streamfetch/download-jobs.json` automatically for durable job state.

For the native window, install the desktop extra and run the launcher:

```bash
pip install -e ".[desktop]"
streamfetch-desktop
```
