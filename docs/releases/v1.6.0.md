_Released 2026-10-22 · Includes the 1.4, 1.5 and 1.6 milestones_

## In one sentence

Build a smarter local collection, find spoken moments without a cloud service,
and listen from a paired phone on your trusted home network.

## What changed

### Added — 1.4: Smart Library & Listening

- Persistent smart playlists combining tags, minimum rating, maximum duration,
  recently added, media type and unplayed status. Rules are evaluated live.
- Background indexing of selected existing folders without copying their media.
  Each watched root remains a separate library with an **Open library** action.
- Persistent timestamped bookmarks, a quick-bookmark player button and embedded
  chapter navigation when FFprobe is installed.
- Playback speed from 0.75× to 2× and a browser-local 15/30/60-minute sleep timer.
- Actual title/artist/album and JPEG/PNG cover writing for MP3, WAV, FLAC, Ogg,
  Opus and MP4/M4A. Full original-file backups are made before atomic replacement.
- Explicit restoration of original-file backups, separate from index-only edits.

### Added — 1.5: Local Speech Search

- Optional faster-whisper transcription on CPU with tiny/base/small models.
  A missing model is downloaded only with explicit consent.
- Background jobs with persistent status, cancellation between decoded segments
  and explicit retry after an interrupted app session.
- SRT/WebVTT import, literal phrase search across ready transcripts and direct
  playback jumps from timestamped results.
- SRT/text export and file-change detection that excludes outdated transcripts
  from search until they are regenerated or reimported.

### Added — 1.6: Listen Everywhere at Home

- A separate mobile web player, sharing just the selected library read-only.
- Track/artist/album search, playlist selection, audio/video playback, next/previous,
  local playback-position restoration, speed and sleep controls.
- Byte-range streaming for seeking without loading the whole file into memory.
- Per-session random pairing codes, HttpOnly/SameSite cookies, 12-hour sessions,
  login throttling, Host/Origin validation and path containment checks.
- Explicit start/stop, session revocation on stop and sharing disabled after restart.
- The StreamFetch logo and dark lilac visual identity in the mobile player.

### Improved and fixed

- A dedicated **Library → Studio** with English/German desktop copy.
- Update backups include watched-folder configuration and every watched library DB;
  smart rules, bookmarks and transcripts remain in their existing library.
- Safe temporary-file handling keeps tag-editing copies out of the media index.
- WAV ID3 and Ogg/Opus picture blocks are recognized by the library.
- Concurrent library readers no longer drop and recreate the queue index.
- Frozen desktop startup dispatches multiprocessing helpers before launching UI.
- Speech dependencies avoid a verified incompatible PyAV major version.
- Same-origin form logins work with CSRF checks and a compatible referrer policy.
- Docker builds include application and branding assets before wheel installation.

## Upgrade notes

Existing media, favorites, playlists, jobs and subscriptions are retained.
Library tables are added in place; no media migration or renaming is required.
Keep `.streamfetch/library.db` as well as your original media in your own backups.

Source installations enable speech with `pip install -e ".[transcription]"`.
Standalone builds include the engine but not a model. Models are cached under
`~/.streamfetch/models/`; the first download contacts Hugging Face. Transcription
then runs locally without sending recordings to a cloud service. Models are not
included in update ZIPs. Interrupted speech jobs need manual retry.

Watched roots live in `~/.streamfetch/watched-folders.json`; scanning needs the
app process to remain running. Tag-editing originals live in each library's
`.streamfetch/tag-backups/`; keep enough free space for a full file copy. Pause
playback before editing. Restoring deliberately replaces the current media file.

The home player uses **unencrypted HTTP**. Use trusted home Wi-Fi only, keep the
computer awake, and never port-forward the sharing port or expose it through a
public tunnel. The administrative app stays loopback-only by default. Stop
sharing to revoke sessions. Mobile interface text is currently English and
playable codecs depend on the phone/browser. This is not a cloud music service.
