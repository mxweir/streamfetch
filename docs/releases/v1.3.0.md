## What changed

### Added

- A dedicated Subscriptions workspace for YouTube channels and playlists plus
  SoundCloud profiles, sets, and playlists.
- Per-source presets, media folders, batch limits, and inspection limits.
- New-item previews with explicit selection before downloads are queued.
- Optional startup and interval checks while StreamFetch is running. These
  checks discover items; they do not start downloads automatically.
- Persistent per-source history, download results, retryable failures, and
  paused-job recovery through the shared download manager.
- Local playlists that follow source order and retain previously downloaded
  items outside the current inspection window.

### Improved

- Shared jobs and source checks across browser sessions avoid duplicate workers.
- Consistent update backups now include subscriptions and each source library.
- Desktop packaging explicitly includes application modules loaded by Streamlit.
- English and German support for the Subscriptions workspace.

## Upgrade notes

Subscription state is stored in `~/.streamfetch/subscriptions.db`. Each source
uses its selected media folder and stores downloads under `Subscriptions/` with
stable per-item paths. The library can index these normally.

Checks inspect up to the configured number of source entries (maximum 500),
in the order returned by the platform. Increase that limit when you need a
wider window. Historical local items are retained; removing a subscription
does not remove files or its local playlist.

Scheduled checks need the StreamFetch process to remain running. Windows
interactive start verification remains a follow-up for the user.
